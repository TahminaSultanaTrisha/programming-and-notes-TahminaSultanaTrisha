# Medical Assistant ChatBot

## About This Project
This chatbot’s built with Python and keeps things simple: it starts with a greeting, checks how you’re feeling, tackles some math, cracks a few jokes, gives you the weather, and then wraps up with a goodbye.

## How to Run
1. Make sure you’ve got Python 3.13.5 or higher.
2. Put all six project files in one folder.
3. Open your terminal (or command prompt) in that folder.
4. Type: `python chatbot.py`
5. Hit Enter and just follow along with the chat.

## Quick Commands
- `python chatbot.py` - Start a regular chat
- `python chatbot.py --test "Hello"` - Test a single message
- `python test_chatbot.py` - Run the tests

## Important Warning :
 **This isn’t real medical advice.** For anything health-related, always talk to an actual doctor.

## What’s in This Project?
1. `chatbot.py` - The main chatbot program
2. `intents.json` - Conversation structure and patterns
3. `knowledge_base.txt` - Extra info
4. `README.md` - You’re reading it
5. `requirements.txt` - Lists what you need (no extra packages)
6. `test_chatbot.py` - For testing things out

## Need Help?:
- Check your Python version with `python --version`
- Double-check all six files are there, in the same folder
- Make sure you’re running everything from that folder
