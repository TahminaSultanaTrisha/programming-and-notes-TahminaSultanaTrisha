What’s a Program?

A program’s basically a list of instructions you hand to a computer so it knows what to do. That’s it.

A Program Can:
- Solve problems
- Do boring or complicated tasks for you
- Focus on one specific thing or handle lots of different stuff
- Be reused by other programmers, if you write it well

“Programming is the art of telling another human being what one wants the computer to do.” — Donald Knuth

Instructions: The Language of Logic

When you program, your instructions have to be:
- Unambiguous. Computers aren’t mind readers.
- In the right order. Mess up the sequence, and the whole thing falls apart.
- Exact. Miss a comma or spell something wrong and the program just stops.

Think of it like:
- Following a recipe to bake a cake
- Building IKEA furniture (good luck)
- Using GPS to get somewhere
- Reading a README file on GitHub

The Three Pillars of Programming

#  Core Programming Components in Python

> These are the building blocks of how programs are structured.

| Component   | What It Means                 | Example (Python style)                          |
|-------------|-------------------------------|------------------------------------------------|
| Sequence    | Steps in order                | `print("Boil water")` → `print("Add tea")` → `print("Pour")` |
| Selection   | Making choices                | `if raining: print("Take an umbrella")`        |
| Repetition  | Doing something over and over | `while soup != "boiling": stir()`              |

Currency Conversion Example (Python)

EXCHANGE_RATE = 0.84

pounds = float(input("How many pounds do you have?"))

if pounds < 0:
    print("You cannot have negative money!")
else:
    euros = pounds * EXCHANGE_RATE
    print("You have", euros, "euros.")

Why Experience Counts

You don’t just learn programming by reading a book. You earn it by doing.

- Anyone can memorize code syntax, but solving real problems takes practice.
- Senior devs work faster because they’ve already faced all sorts of weird situations.
- Experience gives you confidence, creativity, and the grit to push through when things break. And things do break.
