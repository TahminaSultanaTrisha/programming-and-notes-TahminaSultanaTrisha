## **3. Computers and Instructions:** 
Computer Programming Notes 3 : 7th October 2025

1. What is a Computer?
A computer’s basically an electronic machine that takes in data, follows instructions, and spits out results. To remember this, just think “I-P-O”: Input, Process, Output.

Picture it like a chef in the kitchen. Your ingredients are the input, the recipe is the set of instructions, and the finished meal is the output.

2. Instructions & Programs
An instruction is just one command — something you tell the computer to do. A program is a whole set of these instructions working together toward a goal. Here’s a way to remember: “PIP” — Program = Instructions + Purpose.

For example:
print("Hello, World!")  # That’s a single instruction.

3. Machine Language vs High-Level Language
Machine language is pure binary — just 0s and 1s — and the hardware gets it directly. Assembly language is a step up: you use short words like MOV or ADD, so it’s a bit easier for people to read. High-level languages like Python, Java, or C++ are even closer to how we talk.

Here’s a shortcut: “MAP” — Machine, Assembly, Python.

If you want an analogy: Machine language is like Morse code. Assembly is writing quick notes to yourself. High-level languages are full, proper sentences.

4. The Instruction Cycle
Every instruction the computer gets goes through a three-step process:
1. Fetch — grab it from memory
2. Decode — figure out what it’s asking for
3. Execute — actually do it

Easy to remember as “FDE”: Fetch, Decode, Execute.

Take this example:
x = 5 + 3  # The computer fetches the instruction, decodes the plus sign, and then executes by adding and saving the result.

5. Types of Instructions
There are a few main types:
- Data Movement: moves stuff around (like LOAD or STORE)
- Arithmetic: does the math (ADD, SUB)
- Control: changes what happens next (IF, JUMP)

“DAC” — Data, Arithmetic, Control.

For instance:
if x > 0:   # That’s control
    x = x - 1  # That’s arithmetic

6. Memory & Storage
- RAM is your quick, temporary workspace.
- ROM is permanent — you can read it, not write to it.
- Secondary storage is the bigger, slower stuff like hard drives or SSDs.

Think “RRS”: RAM, ROM, Storage.

Picture it like this: RAM is a whiteboard you erase and reuse. ROM is a printed book — what’s there stays there. Storage is a whole library; you keep everything there long term.
