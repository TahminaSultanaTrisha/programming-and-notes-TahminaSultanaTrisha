
## Week 09:  
## **8. Programming Properly: DRY and WET**

Computer Programming Notes 8: 20th November 2025

1. Introduction

Getting code to work is just the start. Good code is easy to read, simple to maintain, and sticks to a consistent style. Today, the focus is on two big ideas: DRY (Don’t Repeat Yourself) and WET (Write Everything Twice).

2. Flashback: A Closing Thought

“I’m finding it really difficult to help you here because you’ve made this much more complicated than it actually is. I recognise some of what you’ve done, but I really don’t know where to start to unpick it.”

When you ignore conventions or overcomplicate things, your code turns into a maze. Nobody wants to untangle that.

3. A Lamentation

Lecturers spend hours building examples, slides, videos—you name it. Still, a lot of students skip over the conventions they’re taught. Most beginners just want their code to run. But here’s the thing: working code isn’t always good code.

4. Working vs. Good Code

Working code spits out the right answer. Good code does more. It’s easy to read, painless to update, and sticks to the rules everyone agreed on.

Fact: You read code about ten times more than you write it. So, think about your future self (or your unlucky teammate) who needs to make sense of it later.

5. Example: Indentation in Python

Python doesn’t mess around with indentation. Four spaces. Not two, not three (unless you’re on your way to four), not five. Six is just nonsense.

When you mess up indentation, your code gets ugly and confusing. It’s harder to follow. Honestly, it just looks like you didn’t care.

6. Reading and Writing

You’ll spend way more time reading code than writing it—seriously, it’s a 10:1 ratio. Sticking to conventions isn’t just for show; it makes life easier for everyone. DRY helps cut down on copy-paste chaos and confusion.

7. Key Acronyms & Mnemonics

DRY: Don’t Repeat Yourself  
Mnemonic: “One idea, one place.”

WET: Write Everything Twice, or We Enjoy Typing  
Mnemonic: “Twice the typing, twice the trouble.”

KISS: Keep It Simple, Stupid  
Mnemonic: “Simplicity saves sanity.”

Just remember: Keep your code DRY, give it a KISS, and don’t get WET.
