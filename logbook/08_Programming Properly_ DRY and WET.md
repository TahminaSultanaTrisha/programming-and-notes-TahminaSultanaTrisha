
# 8. Programming Properly: DRY and WET

** Computer Programming Notes 7: 20th November 2025**

---

## 1. Introduction
- Good code is not only about making it work.
- It must also be **readable, maintainable, and consistent**.
- Focus: **DRY (Don’t Repeat Yourself)** vs. **WET (Write Everything Twice)**.

---

## 2. Flashback: A Closing Thought
> "I'm finding it really difficult to help you here because you've made this much more complicated than it actually is. I recognise some of what you've done, but I really don't know where to start to unpick it."

- Ignoring conventions makes code unnecessarily complex and unreadable.

---

## 3. A Lamentation
- Lecturers prepare examples, slides, videos, and lectures.
- Yet many submissions **ignore conventions taught in class**.
- Beginners often focus only on *getting code to run*.
- But **working code ≠ good code**.

---

## 4. Working vs. Good Code
- **Working Code**: Produces correct output.
- **Good Code**:
  - Readable
  - Maintainable
  - Consistent
  - Follows conventions

 Fact: Code is read **10 times more often than it is written**.

---

## 5. Example: Indentation in Python
- Python **requires indentation**.
- Rule: **Four spaces**.
  - Not 2
  - Not 3 (except on the way to 4)
  - Not 5
  - Six is right out!

Incorrect indentation:
- Harder to read
- Harder to understand
- Looks scruffy (suggests lack of care)

---

## 6. Reading and Writing
- Code is **read more than written (10:1 ratio)**.
- Following conventions makes reading easier.
- DRY principles reduce duplication and confusion.

---

## 7. Key Acronyms & Mnemonics
- **DRY** → Don’t Repeat Yourself  
  Mnemonic: *“One idea, one place.”*
- **WET** → Write Everything Twice / We Enjoy Typing  
  Mnemonic: *“Twice the typing, twice the trouble.”*
- **KISS** → Keep It Simple, Stupid  
  Mnemonic: *“Simplicity saves sanity.”*

 Combined mantra:  
**“Keep your code DRY, give it a KISS, don’t get WET.”**
