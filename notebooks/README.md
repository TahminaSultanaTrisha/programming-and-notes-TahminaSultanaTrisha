# My Jupyter Notebooks

Here’s where I keep all the notebooks I’ve worked on so far. Some are tidy, others are a little messy, but they all chart my progress.

## What’s in here?

- `00_introduction_to_github.ipynb`  
  Figuring out GitHub. Turns out, it’s not just for experts : it actually helps keep things organized and makes sharing code way easier.

- `01_markdown (2).ipynb`  
  Learning Markdown. It’s a simple way to make my notes look good without wrestling with formatting.

- `02_first_programs (1).ipynb`  
  My first Python programs. Some ran, some crashed, but each one taught me something new.

- `03_more_first_programs(1) (1).ipynb`  
  More practice, more bugs, and those moments when things suddenly make sense.

- `04_making_tables (2).ipynb`  
  Playing with tables in both Markdown and Python. It’s like building spreadsheets, but with more control.

- `05_off_the_happy_path (2).ipynb`  
  What happens when code goes sideways and how I tried to fix it.

- `06_using_functions(1).ipynb`  
  Functions! Writing code I can reuse. Honestly, it finally feels like I kind of know what I’m doing.

- `07_data_structures(2).ipynb`  
  Lists, dictionaries, and other ways to stash data in Python.

- `08_file_wrangling (1).ipynb`  
  Reading and writing files. This is where Python starts talking to the outside world.

- `09_command_line.ipynb`  
  The command line used to intimidate me, but now I sort of enjoy it.

##  Why I’m keeping these

- To see how much I’ve improved
- To remind myself how things work when I forget
- To fix stuff I missed the first time
- To have a quick cheat sheet when I need one

All the notebooks are `.ipynb` files. I’ve also stashed a few `.txt` and `.py` files in here : some go with the notebooks, some are from exercises.
